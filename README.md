# 智联招聘助手 · 0.2.4

独立的 Chrome/Edge 招聘辅助扩展，覆盖候选人条件筛选、邀约执行、本地统计和固定话术自动回复。默认使用测试模式，正式操作需要按原有流程确认。

## 文件与功能

| 目录/文件 | 功能 |
| --- | --- |
| `manifest.json` | 扩展名称、权限和入口配置 |
| `popup/` | 候选人筛选、运行控制、统计与日志界面 |
| `options/` | 话术库配置与模拟来信测试 |
| `src/content.js`、`src/core.js` | 页面候选人识别、筛选、去重和邀约控制 |
| `src/reply-content.js`、`src/reply-core.js` | 消息方向识别、话术匹配与回复限制 |
| `tests/`、`scripts/build.ps1` | 自动化测试及扩展打包 |

这是一个 Chrome/Edge Manifest V3 扩展 MVP，用于在用户自己已登录的智联招聘企业页面中辅助扫描候选人、按条件筛选、发起沟通并记录本地统计。

## 已实现

- 关键词、城市和期望薪资筛选；全空时不筛选。
- 本次人数、发送间隔和每日上限。
- 默认测试模式，不点击、不发送。
- 正式模式二次确认、精确按钮文本校验和发送后状态验证。
- 候选人去重、自动滚动、统计、日志和页面诊断。
- 遇到验证码、账号异常、权益不足或结果无法验证时自动暂停。
- 严格话术库：触发词、任一/全部匹配、启用/停用和模拟来信测试。
- 未读来信监听、对方/己方消息方向识别和发送前二次核验。
- 自动回复停止词、每日上限、单会话上限和最小间隔。
- 只发送唯一命中的固定话术；无命中、多规则冲突或方向不明时转人工。

## 本地安装

1. 解压 `ZhaopinInviter-Extension.zip`。
2. Chrome 打开 `chrome://extensions`，Edge 打开 `edge://extensions`。
3. 开启“开发者模式”，选择“加载已解压的扩展程序”。
4. 选择包含 `manifest.json` 的扩展目录。
5. 打开并登录智联招聘企业端，进入候选人/人才推荐页后打开扩展。
6. 首先保持测试模式，点击“页面诊断”确认能识别候选人和沟通按钮。
7. 点击“管理话术库”添加并测试固定话术；自动回复默认关闭。

## 安全边界

- 扩展不保存智联密码或 Cookie，数据保存在浏览器本地存储。
- 不绕过验证码、账号风控、频次限制或付费权益。
- 不批量导出简历或将候选人数据上传到第三方。
- 正式投入使用前，需由智联或委托方确认自动化使用权限和允许范围。

## 实机适配说明

智联页面的 DOM 结构可能随账号、产品版本和地区不同。当前版本已提供严格失败关闭的适配器和诊断信息；首次实机测试应先完成页面诊断，再根据脱敏的页面结构补充稳定选择器。
